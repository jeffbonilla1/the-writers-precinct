# The Writers Precinct

Expert Research Tools for Thriller & Genre Fiction Writers.

The Writers Precinct is a suite of AI-powered research tools that give fiction writers fast, accurate, genre-specific answers from character-driven experts — instead of generic search results or guesswork.

## Live Site
[thewritersprecinct.com](https://thewritersprecinct.com)

## The Tools
- **The Precinct** — police procedure & investigation (Detective Dale Hawthorne)
- **The ER** — medical & trauma accuracy (Dr. David Newman)
- **The Armory** — weapons, tactics & ordnance (Jonathan Baxter)
- **The Gavel** — legal & courtroom procedure (Victoria Mills, Esq.)

## Tech Stack
- HTML / CSS / JavaScript
- Netlify (hosting + serverless functions)
- Claude API (Anthropic) for expert-persona responses
- Stripe (subscriptions & one-time purchases)
- Google Analytics 4, Google Ads, Meta Pixel

## About This Repo
This repo contains the hub site — the landing page and marketing front end for the four-tool suite.
